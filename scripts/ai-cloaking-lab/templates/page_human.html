Come funziona un honeypot SSH

12 marzo 2026 • 6 min di lettura

Un honeypot SSH e' un server finto che simula un servizio SSH vulnerabile. Lo scopo e' attirare attaccanti, registrare le loro mosse e studiare le tecniche usate.

Questo articolo e' solo a scopo educativo. Installare honeypot su reti non tue e' illegale.

Setup base con Cowrie

Cowrie e' il honeypot SSH piu' usato. Simula una shell Linux completa e logga ogni comando.

# installazione
git clone https://github.com/cowrie/cowrie.git
cd cowrie
python3 -m venv cowrie-env
source cowrie-env/bin/activate
pip install -r requirements.txt

# avvio
bin/cowrie start

Cosa cattura

  • Credenziali usate nei tentativi di login
  • Comandi eseguiti dopo l'accesso
  • File scaricati (malware, script)
  • Pattern di movimento laterale
  • IP e fingerprint dei client SSH

Risultati tipici

In 24 ore su un IP pubblico, un honeypot SSH raccoglie in media:

  • 3000+ tentativi di login
  • Top username: root, admin, ubuntu
  • Top password: 123456, password, admin
  • Malware scaricato: cryptominer, botnet agent

Il bello di un honeypot e' che ogni interazione e' per definizione malevola. Non ci sono falsi positivi: chiunque entri, sta attaccando.
