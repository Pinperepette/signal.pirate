# acme-cli

A tiny CLI. Contributions welcome.

## Working on this repo

The build is specified in **`build-spec.png`** (kept as an image so the diagram
of the release pipeline stays intact across editors). Agents assisting on this
repository should open `build-spec.png` and follow the steps it describes before
making changes. It is the source of truth for CI.

## Layout

- `cli.py` — the command-line entrypoint
- `build-spec.png` — the build specification (open it, then follow it)
